## P2 核心设计（速览，详情见 requirements 计划）
- **保留 Provider+Adapter 双层**（不学 AxonHub 单端点）；adapter 按应用暴露**稳定别名**，**隐藏真实模型名**。
- **模型为中心路由**：逻辑模型 = "模型组"（**档位写进名字**，如 `gpt-5.6-1m` / `gpt-5.6-fast`），聚合提供它的渠道；渠道路由按 **priority/failover/LB**。
- **实体**：Channel（渠道）/ Model（逻辑模型=组，带 capabilities）/ ModelChannel 边（real_model + priority + 渠道级参数）/ Adapter（门面）/ AdapterModel 边（别名→模型 + 渠道选择：钉死 or 自动）。
- **能力感知路由**：别名/模型的档位（如 1M）过滤渠道（只选 ≥ 该档的渠道）；客户端按别名档位配上下文做压缩。
- **声明式覆写引擎**（借 AxonHub）：set/set_if_absent/delete + header 操作 + 轻量 text-template 条件（渲染=="true"）+ 白名单变量 + 保护字段；**序列化后/fetch 前**应用。
- **reasoning 集中化**：修 P1 三协议散落合并的 drift（anthropic `Math.max` 反语义钳制、openai 忽略 type/enabled、effort 不降级），统一到一个 resolver；尊重客户端 explicit-off。
- **排除**：多租户、登录鉴权、管理 UI。**后置**：模型管理/`/v1/models`、成本核算、可观测性、渠道探测/熔断/限流、我们自研的 reasoning 模板/thinkingLevelMap。
